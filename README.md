# Fieldwork

Ask a question about your Montgomery neighborhood, and agents find the public data that can answer it, join it in Zetaris, and show the record behind every number.

Answers that used to take an analyst days: the city's own records, CDC health data and census tracts, found, checked and joined live, with every step of the agents' work on screen.

> Work in progress. The first live run is in [`evidence/runs/`](evidence/runs/).

Public documents explain the local information need and intended use of these data: [five primary sources](evidence/need.md), including original Montgomery blight reporting, CDC guidance and original research on local and cross-source planning. The [Desk’s check page](https://fieldwork.38-49-216-59.sslip.io/check) links each exact quotation and its retrieval date. These sources establish a use for public information; they do not establish adoption or measured benefit from Fieldwork.
